# Gogo Mercedes Website Mockup

An unofficial website concept for Gogo Mercedes, designed to demonstrate how her brand, activities, offerings and event announcements could be presented through a modern, responsive website.

## Project Overview

This project is a React + Vite website concept featuring an editorial-inspired design, intuitive navigation and WhatsApp enquiry functionality.

The aim is to explore a potential digital presence that brings key information, community activities and event updates together in one place.

## Features

- Responsive, single-page website layout
- Sticky navigation with smooth anchor links
- Warm ivory, forest green and muted bronze colour palette
- Home, About, Gallery, Offerings, Testimonials, Events and Contact sections
- TikTok-inspired event presentation with links to original posts
- WhatsApp enquiry form with pre-filled messages
- Mobile-friendly layout and navigation
- Placeholder content and imagery for demonstration purposes

## Tech Stack

- React
- JavaScript
- Vite
- CSS
- WhatsApp Click-to-Chat integration

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/TebohoModiba/gogo-mercedes-website-mockup.git
```

2. Navigate into the project directory:

```bash
cd gogo-mercedes-website-mockup
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Configuration

The WhatsApp integration is configured in `src/config.js`.

Before using the contact form publicly, confirm the business's preferred WhatsApp number and ensure it is authorised for this purpose.

## Content and Media

The website currently uses placeholder content and visual treatments for demonstration purposes.

Before presenting it as a finished business website:

- Confirm the biography and business information.
- Verify the actual offerings and event announcements.
- Replace placeholders with owner-approved photographs and videos.
- Add genuine testimonials only with permission.
- Confirm all contact details.
